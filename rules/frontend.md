# Frontend Rules

- Use Next.js App Router and TypeScript.
- Reuse theme-library components before creating new ones.
- Keep pages composable and avoid page-specific duplication when a shared component is appropriate.
- Preserve the existing design tokens in `app/globals.css` unless the user explicitly requests a visual change.
- Validate responsive behavior at 390, 768, 1024 and 1440 widths.
